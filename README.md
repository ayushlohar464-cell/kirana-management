# 🏪 पूनम किराणा (Poonam Kirana) - दुकान व्यवस्थापन प्रणाली

पूनम किराणासाठी तयार केलेली संपूर्ण सप्लायर बिल, बॉक्स हिशोब, उलाढाल व १-वर्षीय नफा-तोटा व्यवस्थापन प्रणाली.

---

## 🌟 प्रमुख वैशिष्ट्ये:
1. **🏪 दुकानाचे नाव:** **पूनम किराणा** (स्क्रीन, बिलांमध्ये आणि Excel रिपोर्टमध्ये हेच नाव दिसेल).
2. **👥 कायमचे सप्लायर्स (Permanent Suppliers):** सप्लायरचे नाव, मोबाईल, पत्ता, आणि एका क्लिकवर **सप्लायर-निहाय Excel (.xls) व CSV रिपोर्ट**.
3. **⚡ एकाच बिलात ४० ते ५० माल एकदम नोंदवा (Multi-Item Bulk Bill Entry):**
   - एकाच बिलात सप्लायर आणि तारीख एकदाच निवडा.
   - **"📋 या सप्लायरचा मागील माल लोड करा"** वर एका क्लिकवर त्या सप्लायरचे सर्व नियमित माल आपोआप टेबलमध्ये लोड होतात.
   - कीबोर्डवरून `Enter` दाबून पटापट नवीन ओळी जोडून एकाच बिलात ४०-५० माल भरता येतात.
   - **"💾 हे संपूर्ण बिल एकदम सेव्ह करा"** वर क्लिक करताच संपूर्ण बिल एकाच वेळी सेव्ह होते.
4. **📷 बिलाचा मूळ फोटो (Camera / Gallery):** ४०-५० मालाच्या मूळ कागदी बिलाचा फोटो एकदाच जोडा, तो सर्व आयटम्ससोबत कायम सेव्ह राहतो.
5. **📑 बिलांनुसार एकत्रित यादी (Invoices View):**
   - बिलांनुसार एकाच ओळीत संपूर्ण बिल (उदा. "४२ माल / आयटम्स, खरेदी ₹४८,५००") दिसते.
   - **"🔍 सर्व माल पहा"** वर क्लिक करून बिलातील सर्व ४०-५० मालाची सविस्तर पावती पाहता येते आणि तिची स्वतंत्र Excel डाऊनलोड करता येते.
6. **📊 १ वर्षाचा नफा आणि उलाढाल (Turnover):** १२ महिन्यांचा रंगीत बार चार्ट आणि ताळेबंद तक्ता.
7. **⬅ मागे जा (Back Button):** कोणत्याही पेजवर गेल्यावर परत येण्यासाठी सोपे Back बटण.
8. **❌ आवश्यकतेनुसार वगळलेले:** स्टॉक अलर्ट नाही, उधारी वही नाही.
